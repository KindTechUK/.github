# .github

Shared files for every repository in the [KindTechUK](https://github.com/KindTechUK) organisation.

| File | What it is for |
| --- | --- |
| `profile/README.md` | The text shown on the organisation's GitHub page |
| `CONTRIBUTING.md` | How to contribute to any Kindtech project |
| `CODE_OF_CONDUCT.md` | How we expect people to treat each other |
| `SECURITY.md` | How to report a security or privacy problem |
| `AI_POLICY.md` | What we ask of contributions made with AI tools |
| `SUPPORT.md` | Where to ask a question |
| `.github/ISSUE_TEMPLATE/` | The forms for reporting a bug or proposing a change |
| `.github/PULL_REQUEST_TEMPLATE.md` | The outline of a pull request description |

GitHub applies these to any Kindtech repository that does not have its own copy of the same file. A repository that needs something different adds its own file, and that file wins.
