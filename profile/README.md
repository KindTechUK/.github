# Kindtech

Open source data and AI tools for charities and social impact organisations, starting with the UK.

Most charities cannot hire a data team. We build the tools a good one would use, keep them open, and make them work with the AI assistants people already have.

## What you can use today

| Project | What it does |
| --- | --- |
| [kindtech](https://github.com/KindTechUK/kindtech) | Python package for UK public data: area boundaries, official statistics, postcodes and deprivation indices for all four nations. Includes worked charity case studies you can run in the browser. [Docs](https://kindtechuk.github.io/kindtech/) |
| [open-foi](https://github.com/KindTechUK/open-foi) | Command-line search of Freedom of Information requests on WhatDoTheyKnow |
| [awesome-charity-ai-use-cases](https://github.com/KindTechUK/awesome-charity-ai-use-cases) | A list of real examples of charities using AI, with what they learned |

## Opening up soon

- A research tool that keeps a source for every fact it records.
- A transcription app that runs entirely on your own computer.
- Skills and connectors that bring UK charity know-how and open data into AI assistants.

## Get involved

You do not need to write code to help.

- **Work at a charity?** Add an example to the [use cases list](https://github.com/KindTechUK/awesome-charity-ai-use-cases), or open an issue to tell us which question you cannot answer with your data today.
- **Work with data or code?** Read the [contributing guide](https://github.com/KindTechUK/.github/blob/main/CONTRIBUTING.md). The most useful first contributions are a new data source or a worked analysis.
- **Using an AI assistant to contribute?** That is welcome. Read the [AI policy](https://github.com/KindTechUK/.github/blob/main/AI_POLICY.md) first.

Found a security or privacy problem? Please [report it privately](https://github.com/KindTechUK/.github/blob/main/SECURITY.md).
