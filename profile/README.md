# Kindtech

Open source data and AI tools for charities and social impact organisations, starting with the UK.

Most charities cannot hire a data team. We build the tools a good one would use, keep them open, and make them work with the AI assistants people already have.

## What we are building

Seven projects with one aim: a small charity should be able to answer its own questions, with its own data, without handing that data to anyone.

| Project | What it does | Where it is |
| --- | --- | --- |
| [uk-open-data](https://github.com/KindTechUK/uk-open-data) | Python package for UK open data: area boundaries, official statistics, postcodes and deprivation indices for all four nations. Includes worked charity case studies you can run in the browser. Up to version 0.1 it was called `kindtech`. [Docs](https://kindtechuk.github.io/uk-open-data/) | Use it today |
| [Skills for AI assistants](https://github.com/KindTechUK/plugins) | Skills that bring UK charity know-how and UK open data into the assistant you already use. The first helps write the evidence of local need for a grant application. | Early version |
| [open-foi](https://github.com/KindTechUK/open-foi) | Command-line search of Freedom of Information requests on WhatDoTheyKnow | Use it today |
| [Charity AI use cases](https://github.com/KindTechUK/awesome-charity-ai-use-cases) | A list of real examples of charities using AI, with what they learned | Use it today |
| Kindtech Evidence | Ready-made analyses that set your data against UK open data: who you reach, where need is high, who you miss. Each gives figures you can quote, a map and the working. The analyses are in the uk-open-data package today. | Opening soon |
| Research graph | A research tool that keeps a source for every fact it records | Opening soon |
| Folio | A transcription app that runs entirely on your own computer | Opening soon |

## Get involved

You do not need to write code to help.

- **Work at a charity?** Add an example to the [use cases list](https://github.com/KindTechUK/awesome-charity-ai-use-cases), or open an issue to tell us which question you cannot answer with your data today.
- **Work with data or code?** Read the [contributing guide](https://github.com/KindTechUK/.github/blob/main/CONTRIBUTING.md). The most useful first contributions are a new data source or a worked analysis.
- **Using an AI assistant to contribute?** That is welcome. Read the [AI policy](https://github.com/KindTechUK/.github/blob/main/AI_POLICY.md) first.

Found a security or privacy problem? Please [report it privately](https://github.com/KindTechUK/.github/blob/main/SECURITY.md).
