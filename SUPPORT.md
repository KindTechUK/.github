# Getting help

- **Something is broken.** Open an issue on the repository concerned, using the bug report form.
- **You have an idea or a request.** Open an issue using the proposal form. Say what you are trying to do and who it is for.
- **You are not sure how to do something.** Check the project's docs first, then open an issue and ask. A question that the docs should have answered is a useful issue.
- **A security or privacy problem.** Do not open a public issue. See the [security policy](SECURITY.md).

Kindtech projects are maintained by a small team. We aim to reply within two working days. There is no guaranteed support for the open source tools.

Please do not include personal data about real people in anything you post.
